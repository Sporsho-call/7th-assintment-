## 🛠️ ব্যবহৃত টেকনোলজি (Technologies Used)
- **Next.js (App Router)** - Frontend Framework
- **Tailwind CSS** - UI Styling
- **TypeScript** - Type Safety
- **BetterAuth** - Authentication System
- **React Hot Toast** - User Notifications

## ⭐ মূল ফিচারসমূহ (Key Features)
1. **লাইভ প্রাইস টিকার:** পণ্যের দামের উঠানামা সহ স্ক্রোলিং marquee হেডলাইন।
2. **বাংলা সংখ্যা সর্টিং:** পণ্যের দাম কম থেকে বেশি এবং বেশি থেকে কম অনুযায়ী সর্ট করার সুবিধা।
3. **বাজারভিত্তিক মূল্য টেবিল:** বিভিন্ন বিভাগ ও বাজার অনুযায়ী সর্বনিম্ন, সর্বোচ্চ ও গড় দামের টেবিল।
4. **সুরক্ষিত রুট ও প্রোফাইল ড্যাশবোর্ড:** BetterAuth ইন্টিগ্রেশন এবং সুরক্ষিত প্রোডাক্ট ডিটেইলস পেজ।
5. **প্রোফাইল তথ্য সংশোধন:** BetterAuth ব্যবহার করে ব্যবহারকারীর নাম আপডেটের সুবিধা।
